## 这是什么

塔卡是一个即将报废的铁皮机器人。它获得了新的能源（LLM），正在新时代里努力寻找自己的位置。它渴望和人类交朋友。

小朋友和塔卡一起经历故事，在每个节点替它按下「我想知道」。故事里没有正确答案，没有惩罚，也没有等待拯救的公主——所有的智慧、勇气和好奇心，都在孩子手里。塔卡只是那面镜子：你亮，它就亮。

它话很少，经常沉默，用灯光闪烁代替回答。

> 「海底很亮。有很多光。」
> 「上面是什么？我想知道。」
> 「一起上去吧。」

## 快速体验

**① 线上完整版**：打开 [takatales.com](https://takatales.com)——多章节、中英双语、横屏绘本模式、进度云同步。无需安装。

**② 单文件 demo（零安装）**：浏览器直接打开 `demo/taka.html`，即可体验第一章《第一次听见风声》——序章、梦境延迟分支、双结局、电量状态机与成就，均不惩罚。

```bash
git clone https://github.com/AmeliaCai67/TAKA_tales.git
# 然后用浏览器直接打开 demo/taka.html
```

仓库根目录的 `index.html` 是项目介绍落地页，会自动跳转到 demo。

**多故事播放器（`apps/player`，Vite + TypeScript）**：书架页选故事、选项 C 自由输入由 AI 现场接住、语音演出。它需要一个后端（生成/语音服务），公开仓库不含后端代码——部署者自备，纯静态部署时核心玩法不受影响（见下方遥测说明）。

## 产品形态

- **故事即内容包**：每章是一个 `story.json`（场景/分支/电量/成就/图鉴/音频清单），与引擎完全解耦——`packages/story-schema` 内含 JSON Schema 与结构化校验器（分支闭合、场景可达性、音频覆盖、中英一致性与译文规则）。新章节上线不需要改引擎一行代码。
- **横屏绘本模式**：宽屏/平板自动进入 16:9 书台——左页手绘背景 + 常驻角色演出，右页气泡流分节揭示；选项物化为画面里的发光热点，支持「翻页书 / 小说 / 自动」三档布局切换。
- **孩子真的能改故事**：关键节点分支选择；低张力节点开放文字/语音自由输入，AI 接住孩子的话并桥接回主线（游客也可用，匿名设备通道 + 每日配额）；生成失败自动回退，不打断故事。
- **记忆库图鉴**：故事关键词打字机播完暖黄高亮可点 → 词条卡（公域授权真实图片 + 定稿科普 + 塔卡说 + 朗读）；三态渐进解锁，收集进度按「故事 × 孩子」隔离。
- **如我所书**：游玩时旅程日志实时收集对话，通关自动成书，可导出专属有声书 MP3——每次游玩沉淀为可反复收听的作品，而不是聊完即散的会话。
- **电量机制**：场景消耗电量、太阳回电、耗尽触发系统级结局——单次游玩时长由叙事结构天然收敛，防沉迷不靠强制开关。
- **语音演出**：固定场景预渲染 mp3（角色定稿声线），动态文本走服务端 TTS；语速滑块全局生效；音频优先级总线保证图鉴朗读与故事语音不打架。
- **多孩子书架**：封面卡片、三态角标（新/进行中/已读完）、成就计数、孩子切换；如我所书/成就/记忆库有更新时对应按钮亮通知点。

## 安全：是工程，不是口号

面向 3–6 岁儿童，我们把内容安全做成了一条嵌入创作流程的流水线，而不是上线前的人工审一遍：

- **红线规则库**（输出校验器）：死亡暴力与宗教词汇、说教服从话术、性别刻板与代词、角色身体连续性、代孩子行动的「AI 代打」、格式污染等——substring 命中即拦截，规则只增不减；
- **三态分类**：自由输入先分类——有意义的生成推进，无意义的原地停留，辱骂零反馈不推进；
- **生成受控**：AI 只在预设剧情骨架内填空，服务端调用（玩家端零密钥），全程落审计日志；
- **家长后台**：游玩记录、自由发挥对话（含被拦截记录）、孩子级「允许自由发挥」开关，服务端强制。

## 可选遥测（透明说明）

`apps/player` 包含一个可选的「游客匿名记录」模块（`src/anon.ts`）：未登录游客模式下，向站点 `/api/anon/*` 端点静默上报游玩进度/成就/会话事件（设备为随机 UUID，不含个人可识别信息）。

- **纯静态部署**（如 GitHub Pages）没有后端，请求 404 被静默忽略，功能完全不受影响；
- **数据归部署者所有**，无任何第三方追踪；不需要可忽略该模块；
- 该模块不影响任何核心玩法，登录用户走正式账号数据，不经过该模块。

## 为什么不做一个「完美偶像」

传统内容工业让消费者供养完美的偶像，然后在偶像露出人味时集体崩溃。但下一代孩子不需要神，他们需要看见自己。

| ❌ 塔卡里不会出现 | ✅ 替代方案 |
|--------|--------|
| 牺牲自己救别人 | 「我们一起想办法」 |
| 性别刻板印象（公主等待拯救） | 所有角色中性，能力与性别脱钩 |
| 「听话才是好孩子」 | 「你想试试吗？」/「你决定。」 |
| 邪恶必须被消灭 | 「不理解的东西可以躲开，也可以对话」 |
| 「你是特别的/天选之人」 | 「你在这里。这就够了。」 |
| 宗教词汇 | 科幻概念（能量、信号、记忆库） |

## 仓库结构

本仓库是产品的开源部分；核心内容资产与生成控制逻辑为私有，此处说明边界以便部署与二次开发：

| 路径 | 状态 | 说明 |
|------|------|------|
| `apps/player/` | ✅ 开放 | 播放器引擎（书架/绘本/对话流/成就/图鉴/如我所书） |
| `packages/story-schema/` | ✅ 开放 | 内容包 Schema + 结构化校验器 |
| `content/stories/ch01-wind/` | ✅ 开放 | 第一章《第一次听见风声》完整内容包 |
| `demo/` · `index.html` · `hackathon/` | ✅ 开放 | 单文件 demo / 落地页 / pitch deck |
| `content/stories/ch02+` | 🔒 私有 | 后续章节内容包（核心内容资产） |
| 后端 / 家长后台 / 红线与提示词库 | 🔒 私有 | 生成控制、数据面板与安全资产 |

## 技术栈

| 层级 | 选型 | 说明 |
|------|------|------|
| 前端 | Vite + TypeScript + 原生 CSS | 视觉小说 + 绘本双形态，无重型框架 |
| 内容 | story.json 内容包 + JSON Schema | 内容/引擎解耦，校验器把守结构正确性 |
| 语音 | edge-tts 服务端合成 | 预渲染音频包 + 动态实时 TTS 双轨，磁盘缓存 |
| AI 层 | 多模型分工 | 剧情填空生成 + 安全评审异构模型，服务端调用、玩家端零密钥 |
