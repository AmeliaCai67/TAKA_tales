# 塔卡故事 TAKA Tales — 儿童 AI 互动有声故事

> **中文** | [English](README.en.md)

> **一句话介绍**：面向 3–6 岁儿童的 AI 互动叙事产品。孩子通过选择和自由对话推进剧情，完成一个章节后，生成专属的有声故事书。

**线上体验**：[takatales.com](https://takatales.com)（手机/平板浏览器直接可玩，已上线四章中英双语内容）

---

## 故事与主角

主角塔卡是一个旧铁皮机器人。它获得了新能源（LLM），在新的世界里努力寻找自己的位置，渴望和人类交朋友。

它话不多，经常用闪烁的灯光代替回答。故事里没有标准答案，也没有惩罚机制。孩子在每个节点替它做选择或表达想法，塔卡会根据孩子的反馈做出回应，陪孩子一起探索世界。

> 「海底很亮。有很多光。」
> 「上面是什么？我想知道。」
> 「一起上去吧。」

## 产品特性

- **能听能玩的互动绘本**：手绘风格配图 + 角色配音，支持手机竖屏与平板横屏阅读。
- **开放式交互**：除了预设分支，孩子可以通过文字或语音自由表达想法，AI 角色会实时响应并承接剧情。
- **趣味知识拓展**：点击故事中发光的关键词（如真实的鲸、猫、深海现象），解锁科普卡片并存入「记忆库」。
- **专属故事生成与导出**：通关后，系统会将孩子游玩过程中的选择与对话整理为「如我所书」故事集，支持导出有声书供日常回放。
- **家长面板与进度同步**：记录孩子的阅读路径与对话记录，支持多孩子档案管理与多端同步。

## 安全防护与工程控制

针对 3–6 岁儿童的交互场景，内容安全通过以下工程机制控制：

- **红线规则库（输出拦截）**：检查暴力、说教服从、性别刻板印象、角色行为越界及格式污染等内容，未通过校验的生成结果不返回给玩家。
- **输入三态分类**：自由输入优先分类，有效输入生成并推进剧情，无意义输入原地保持，脏话输入不触发生成，沿定稿主线继续。
- **受控生成（Bounded Generation）**：AI 仅在预设的剧情骨架内填空生成，采用服务端调用（客户端零 API Key），全程记录审计日志。
- **家长控制**：后台提供自由发挥对话日志（含被拦截记录），并支持服务端强制的自由发挥开关。
- **身份验证**：基于品牌邮箱的 SMTP 验证码登录，生产环境禁止在 API 响应中回显验证码；SMTP 连接校验服务器证书与主机名，发信失败返回错误。


## 技术栈

- **前端引擎**：Vite + TypeScript + 原生 CSS，支持视觉小说与绘本两种交互布局。
- **内容协议**：`story.json` 内容包 + JSON Schema，校验故事结构、分支可达性与音频覆盖。
- **语音合成**：阿里云 CosyVoice（DashScope），采用预渲染音频包与动态 TTS 双轨机制，具备抗抖动与磁盘缓存策略。
- **模型分工**：剧情生成与离线安全评审使用不同模型，服务端管理模型调用与凭据。

## 可选遥测

`apps/player/src/anon.ts` 在游客模式下使用随机设备标识，向部署站点的 `/api/anon/*` 上报游玩进度、成就与会话事件。数据由部署者管理，无第三方追踪；登录用户走账号数据通道。该模块可移除，纯静态部署时上报失败不影响本地游玩。
