# 塔卡 TAKA — AI 互动童话

> **一句话定位**：面向 3-6 岁儿童的 AI 互动叙事产品，通过中性机器人角色引导小朋友在极简分支故事中做出选择，培养自主性、好奇心与主体意识。
>
> **核心主张**：我们不造神，我们造镜子。镜子不会塌房。

![Status](https://img.shields.io/badge/status-MVP%20prototype-orange)

---

## 这是什么

塔卡是一个即将报废的铁皮机器人。它获得了新的能源（LLM），正在新时代里努力寻找自己的位置。它渴望和人类交朋友。

小朋友和塔卡一起经历故事，在每个节点替它按下「我想知道」。故事里没有正确答案，没有惩罚，也没有等待拯救的公主——所有的智慧、勇气和好奇心，都在孩子手里。塔卡只是那面镜子：你亮，它就亮。

它话很少。每次说话不超过 15 个字，经常沉默，用灯光闪烁代替回答。

> 「海底很亮。有很多光。」
> 「上面是什么？我想知道。」
> 「一起上去吧。」

## 快速体验

当前 MVP 是单文件 HTML 原型，无需安装任何东西：

```bash
git clone https://github.com/AmeliaCai67/TAKA_tales.git
# 然后用浏览器直接打开 demo/taka.html
```

仓库根目录的 `index.html` 是项目介绍落地页，会自动跳转到 demo。首个故事《第一次听见风声》：塔卡在海底听到海面传来「呼呼」声——游上去，还是继续清理珊瑚？包含序章、梦境延迟分支、3 层主线选择和双结局，均不惩罚。

### 当前 MVP 已支持

- 浏览器原生中文语音朗读，按角色区分语气；支持语音开关、语速滑块和试听。
- 首次点击启动门，兼容 Chrome/Safari 的语音播放权限限制；语音不可用时仍可静默体验。
- OpenAI-compatible API 设置面板：Base URL、模型和 API Key 只保存在本机 `localStorage`，AI 生成失败自动回退内置文案。
- 固定选项之外支持自由输入：可键入或用浏览器语音识别表达自己的选择，由 AI 接住后回到故事骨架。
- 全局电量状态机与电池 HUD：场景消耗、电量档位、太阳回电和耗尽时的系统级结局都会影响塔卡灯光。
- 5 个可持久化成就，支持解锁 toast 和成就查看弹窗。
- 视觉小说式打字机文本、点击补完、思考闪烁预告、聆听进度条，以及水下收腿/陆地站立双立绘模式。
- 横屏视觉小说布局与竖屏降级布局；长文本在移动端通过页面滚动阅读。

## 为什么不做一个「完美偶像」

传统内容工业让消费者供养完美的偶像，然后在偶像露出人味时集体崩溃。但下一代孩子不需要神，他们需要看见自己。

| ❌ 塔卡里不会出现 | ✅ 替代方案 |
|--------|--------|
| 牺牲自己救别人 | 「我们一起想办法」 |
| 性别刻板印象（公主等待拯救） | 所有角色中性，能力与性别脱钩 |
| 「听话才是好孩子」 | 「你想试试吗？」/「你决定。」 |
| 邪恶必须被消灭 | 「不理解的东西可以躲开，也可以对话」 |
| 「你是特别的/天选之人」 | 「你在这里。这就够了。」 |
| 宗教词汇 | 科幻概念（能量、信号、记忆库） |

## 技术栈

| 层级 | 选型 | 说明 |
|------|------|------|
| 前端 | Vite + 原生 CSS | 复古工业终端风，深海网格 + 暖黄光源，打字机文本 |
| 后端 | FastAPI (Python) | 故事状态机，JSON 存进度 |
| AI 层 | DeepSeek / Kimi API | 预设骨架内填空式生成，非自由发挥 |
| 内容安全 | Prompt 级红线过滤 + 家长后台 + 物理暂停键 | 白名单生成，全程可审计 |
| 部署 | 阿里云 ECS | 与现有项目共用资源 |
